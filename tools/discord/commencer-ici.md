# 🔥 Bienvenue dans Diablofus : Les Douze Enfers
Le Monde des Douze en action-RPG **temps réel**, dans le navigateur, sur PC (clavier + souris). Gratuit, sans compte ni téléchargement.

🔗 **Jouer : https://diablofus.com**

## 🎮 Les touches
- **Clic gauche** : se déplacer, attaquer un monstre (maintenu : continuer) · **Maj + clic** : attaquer sur place
- **Clic droit** : sort favori · **1 à 6** : barre de sorts · **Espace** : bond
- **E** : potion · **M** : carte · **H** : Havre-Sac · **G** : guide
- **I** inventaire · **C** caractéristiques · **S** sorts · **J** métiers · **B** bestiaire · **O** options · **Échap** : fermer
